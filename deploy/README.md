# Репетиция деплоя проекта ÉLAN

## 1. Схема архитектуры
Браузер -> Nginx (порт 443, HTTPS) -> React (статические файлы).

## 2. Таблица сервисов
| Сервис | Технология | Внутренний порт | Продакшен-сервер |
| :--- | :--- | :--- | :--- |
| frontend | React + Vite | 80 | Nginx |
| nginx | Nginx | 80, 443 | - |

## 3. Переменные окружения и секреты
Проект не использует базу данных, поэтому секретов нет. 
Для работы HTTPS сгенерированы локальные сертификаты (папка certs, исключена из Git).

## 4. Команды для запуска и остановки
- Запуск: `docker compose up --build -d`
- Остановка: `docker compose down`
- Проверка статуса: `docker compose ps`

## 6. Ошибки и способы их устранения
1. **Ошибка `additional properties 'nginx' not allowed`**: 
   *Причина:* Нарушение отступов в `docker-compose.yml`.
   *Решение:* Исправлены отступы, YAML очень чувствителен к пробелам.
2. **Nginx отдавал стандартную страницу "Welcome to nginx!":**
   *Причина:* Файл `nginx.conf` не подхватывался через `volumes`.
   *Решение:* Создан `Dockerfile` для Nginx, который копирует конфиг внутрь образа при сборке.
3. **Отсутствовали файлы сайта:**
   *Причина:* Nginx не знал, откуда брать статику.
   *Решение:* В `docker-compose.yml` добавлено монтирование папки `../frontend/dist:/usr/share/nginx/html:ro`.

## 7. Что нужно для публикации на реальном сервере?
1. Арендовать сервер (например, на Linux).
2. Купить реальный домен (например, elan-store.ru) и настроить DNS.
3. Получить настоящий SSL-сертификат (через Let's Encrypt и Certbot).
4. Настроить CI/CD (GitHub Actions), чтобы он автоматически собирал образ и разворачивал его на сервере по SSH.
