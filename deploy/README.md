# Деплой проекта ÉLAN (Практика 76-78)

## 1. Схема архитектуры
Браузер -> Nginx (HTTPS, порт 443) -> React (Frontend).

## 2. Таблица сервисов
| Сервис | Технология | Внутренний порт | Продакшен-сервер |
| :--- | :--- | :--- | :--- |
| frontend | React + Vite | 80 | Nginx |
| nginx | Nginx | 80, 443 | - |

## 3. Секреты и переменные
В `docker-compose.yml` передаются переменные для подключения к Supabase:
- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`
Сертификаты для HTTPS лежат в папке `certs/` (исключены из Git через `.gitignore`).

## 4. Команды управления
- Запуск: `docker compose up --build -d`
- Остановка: `docker compose down`
- Статус: `docker compose ps`

## 5. Скриншоты
*(Прикрепите сюда ваши скриншоты)*
- Скриншот `docker compose ps` (контейнеры в статусе Up).
- Скриншот сайта https://elan.localhost с замком.

## 6. Ошибки и решения
1. **Ошибка сертификата**: перевыпустили через mkcert.
2. **Ошибка 404 при обновлении**: добавили `try_files` в Nginx.
3. **Ошибка кодировки в robots.txt**: сохранили файл в UTF-8.

## 7. Что нужно для публикации на реальном сервере? (Пункт 7)
1. Арендовать VPS-сервер (например, на Linux).
2. Купить реальный домен (например, elan-store.ru) и настроить DNS (A-запись).
3. Получить SSL-сертификат через Let's Encrypt (Certbot).
4. Настроить CI/CD (GitHub Actions) для автоматической сборки образа и его деплоя на сервер по SSH (Continuous Deployment).
